TGP Pagella, TGP Pagella Math: subsets of TeX Gyre Pagella and TeX Gyre Pagella Math (GUST e-foundry), renamed
for the GUST Font License (GUST-FONT-LICENSE.txt).
TGP Symbol Math: a subset of STIX Two Math (The STIX Fonts Project Authors), renamed for the SIL Open Font
License 1.1 (OFL-STIX-Two.txt; Reserved Font Name TM Math); it supplies the signs Pagella Math lacks.
Lab Sans: subsets of Selawik 1.01 (Microsoft Corporation), renamed because Selawik is a Reserved Font Name
under the SIL Open Font License 1.1 (OFL-Selawik.txt). Lab Sans is a modified version of Selawik.
